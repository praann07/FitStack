## Phase 1 Complete: Critical Database & Approval System Fixes

### WHAT
- Created migration 0011 to fix schema integrity issues
- Enhanced PendingApprovalPage with real-time approval polling + timeline
- Added polling support to useAsync hook
- Added getCurrentProfile() method to authService

### WHY
Database audit (2026-08-29) identified critical issues:
- Missing CHECK constraints on enums (set_type, meal_type, confidence)
- Nullable meal_type breaking nutrition tracking
- Missing indexes causing 21k query dashboard issue
- User experience: PendingApprovalPage was passive ("check back") with no feedback

### HOW
**Database (migration 0011):**
- Added CHECK constraints to workout_sets.set_type, food_logs.meal_type, tdee_estimates.confidence
- Made meal_type NOT NULL (backfilled null values to 'other')
- Added 4 composite indexes for query performance (user_id, log_date DESC patterns)
- Note: UNIQUE constraints already existed in migration 0010

**Frontend Approval UX:**
- PendingApprovalPage now polls approval status every 3 seconds
- Shows visual timeline: Account Created → Awaiting Admin Review → Approved
- Auto-redirects to dashboard when approved (no manual refresh needed)
- Displays helpful context: "review during business hours, usually within a few hours"
- Manual "Check now" button for impatient users
- Error state if polling fails

**Infrastructure:**
- useAsync hook enhanced with `interval` option for automatic polling
- authService.getCurrentProfile() fetches current user's profile (used by polling)

### IMPACT
✅ **Database integrity:** CHECK constraints prevent bad data at source  
✅ **Query performance:** Indexes unblock the 21k query dashboard issue  
✅ **User experience:** Approval no longer feels like a dead-end; users see real-time feedback  
✅ **Type-safety:** All TypeScript changes verified (npx tsc --noEmit passed)

### RISKS / UNKNOWNS
- Email notifications on approval not yet implemented (blocked on Resend domain KYC per audit notes)
- No fallback if polling fails continuously (error state shown but no retry loop)
